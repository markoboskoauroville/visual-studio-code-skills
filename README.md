# Visual Studio Code Skills

Durable, verified operating skills for Copilot/VS Code sessions on Marko's Mac.

Every skill lives at `skills/<name>/SKILL.md` with YAML frontmatter. When a session produces a new verified,
repeatable rule, use `write-a-skill` to add or update it in this repository.

## Skills

- `write-a-skill` — captures new lessons as reusable skills
- `macro-recorder-control` — controls the Mac through Macro Recorder (Mantra)
- `terminal-control` — opens and uses a visible Terminal safely
- `pixel-ltc-safety` — controls Pixel LTC and volume without leaving the harmful test sound running
- `davinci-resolve-ltc-timecode` — imports LTC recordings and sets Resolve clip Start TC through the router
